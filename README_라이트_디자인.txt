누리 키우기 · 밝은 모바일 게임 UI 리디자인 (2026-11-15)

PC·모바일 공통 화면을 밝은 회색 배경 + 둥근 흰색 카드 + 파란 버튼 디자인으로 바꾼 버전입니다.

1. 압축을 풀고 폴더 전체를 Netlify에 배포하세요. 루트의 index.html, game.js, account.js,
   account.css, light-ui.css, light-ui.js, auth-config.js, assets/ 전체가 함께 있어야 합니다.
2. PC 타이틀 로딩 화면 → 회원가입/로그인 또는 게스트 선택 → 가족 선택 → 게임 플레이 순서입니다.
3. 게스트 로그인은 바로 작동합니다. 실제 회원가입/클라우드 저장은 Supabase 인증 서버
   설정이 필요합니다. README_설치방법.txt 와 supabase_setup.sql 내용을 확인하세요.
4. 기존 게임의 저장 데이터와 가족·경제·연애·스토리·사진첩 등 기능을 유지했습니다.
5. 특별 사진첩에 포함된 개인 사진은 정적 파일로 배포하므로 공개 사이트 방문자가
   이미지 파일을 열람할 수 있습니다. 공개 배포 전에 사진 공개에 동의하는지 확인하세요.
6. 배포 후 문제가 생기면 mobile-check.html에서 모바일 터치 진단이 가능합니다.

테스트: Chromium 모바일 화면(390px) 및 PC(1280px)에서 게스트 입장, 가족 선택,
일반/스토리 선택, 메뉴/설정/사진첩 열기, 주요 기능 화면 및 문법 검사를 완료했습니다.
실제 아이폰 Safari는 별도 확인이 필요합니다.
