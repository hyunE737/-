누리 키우기 · 최종 오리지널 디자인 버전 (2026-11-16)

테마: 인생 다이어리 · 따뜻한 종이톤 + 청록 + 살구색 + 픽셀 캐릭터
이전의 파란색/흰색 랭킹앱 디자인을 그대로 모방하지 않고 독자적인 디자인으로 제작했습니다.

배포 방법
1. 이 ZIP을 압축 해제합니다.
2. 폴더 전체 내용(index.html, game.js, assets, CSS, account.js 등)을 Netlify 기존 사이트 Deploys에 올립니다.
3. 기존 게스트 저장 데이터는 해당 브라우저의 저장소에 유지됩니다.
4. 회원가입·클라우드 저장을 이용하려면 auth-config.js와 supabase_setup.sql 설정이 필요합니다.
5. 건의/신고 접수는 Netlify Forms에서 양식 감지를 활성화한 뒤 다시 배포해야 합니다.

주의: 특별 사진첩에 개인 사진이 들어 있습니다. 공개 배포하면 방문자가 이미지 URL/파일을 볼 수 있습니다.
실제 iPhone Safari 및 계정 서버가 연결된 환경의 테스트는 별도로 필요합니다.
