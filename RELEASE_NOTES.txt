누리 키우기 · v1.0.0 출시 후보 / 2026-11-16

최종 게임 디자인: 크림·청록·살구색 '누리의 인생 다이어리'
게임 포함: 가족 4종, 스토리, 빠른 성장, 건강, 노화, 주식/부동산/창업/대출,
월급/승진, 재능, 업적, 특별 이벤트 사진첩, 연애/결혼/이혼/자녀,
군대/진로/취업, 병맛 사건, 인생 회고록, 종료 후 재시작, 게스트 로그인.

기본 테스트 결과:
- 모바일 390px 및 PC 1280px에서 버튼/메뉴 포함 121개 항목 통과
- 자동 진행 100세 엔딩 (345회 선택, 사진 9장 획득) 오류 없음
- JS 문법 및 내부 리소스/ZIP 무결성 검사 통과
- 실제 아이폰 Safari, 실제 Netlify Form 전송, 실제 Supabase 로그인은 검증하지 못함

운영 전 반드시 확인:
1) Supabase 실제 회원가입이 필요하면 auth-config.js 설정, supabase_setup.sql 실행,
   로그인/이메일 확인/클라우드 저장 실제 테스트.
2) Netlify Forms > Enable form detection 설정 후 다시 배포, 테스트 글 제출.
3) 크롬/사파리 실제 스마트폰에서 전체 플레이 및 버튼 테스트.
4) 사용자 이미지/개인정보 포함 여부와 공개 동의 검토.
5) 운영자 개인정보 처리 안내 및 서비스 소개/문의 방법 게시.
6) 해당 ZIP을 압축 해제한 폴더 전체를 Netlify Deploys에 올리기.

아직 서버에 배포하지 않았으며 게스트 모드만 무설정 이용 가능.

[공개 권장판] 실제 인물 사진 9장을 삭제하고 게임 캐릭터 그림으로 대체함. 사진첩 해금 기능 자체는 유지됨.
